# 参考文献

本项目参考课程提供的抗辐照 SRAM 论文，当前阶段采用 HPHS12T 结构进行工艺适配和电路级仿真。

## HPHS12T

Zhongyang Liu, Haineng Zhang, Yuqiao Xie, Dawei Bi, Zhiyuan Hu, Shichang Zou, Zhengxuan Zhang. High-performance and highly-stable soft error resistant 12T SRAM cell for space applications. Microelectronics Reliability, 141 (2023), 114885.

[论文 DOI 与出版页面](https://doi.org/10.1016/j.microrel.2022.114885)

原文采用 55 nm 工艺和 1.2 V 供电。本仓库采用课程环境中的 180 nm 工艺和 1.8 V 供电，结果取自本项目的实际仿真。原论文性能数据不作为本项目的测量结果。

课程提供的其他论文原件保留在本地资料目录中。
